# AI-Use Disclosure

*Fill this in honestly as you complete the project. The rubric (5%) asks for
three things: where/how AI was used, how AI output was checked, and important
AI errors or suggestions you corrected or rejected.*

## 1. Where and how AI was used

- [ ] Framing / understanding the paper and design
- [ ] Data cleaning and variable construction
- [ ] Writing analysis code (which scripts)
- [ ] Generating figures/tables
- [ ] Drafting / editing the report
- [ ] Debugging / interpreting results

Describe concretely (e.g. "used an AI assistant to draft `src/table4.py` and
explain the GAP variable definition").

## 2. How AI-generated code, analysis, and writing were checked

- [ ] Ran every script and inspected the outputs against the paper
- [ ] Read and understood each line of generated code before using it
- [ ] Verified variable definitions against the data dictionary and the paper
- [ ] Manually recomputed key numbers (e.g. the 2.76 DID estimate)
- [ ] Cross-checked t-stats / SEs by hand or with a second implementation

## 3. Important AI errors or suggestions that I corrected or rejected

List specific examples, e.g.:
- (example) "AI initially defined GAP using a $5.00 threshold; I corrected it to
  $5.05 per the paper's Table 4 note."
- (example) "AI suggested dropping stores with missing wave-2 employment; I
  rejected this because the paper's closure adjustment sets permanently-closed
  stores to zero."

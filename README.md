# Card & Krueger (1994) — Replication and Extension

ECON6067 Individual Project. AI-assisted empirical replication and extension of

> Card, D. & Krueger, A. B. (1994). "Minimum Wages and Employment: A Case Study
> of the Fast-Food Industry in New Jersey and Pennsylvania." *American Economic
> Review*, 84(4), 772–793.

**Research question.** Did New Jersey's April 1, 1992 minimum-wage increase
(from $4.25 to $5.05) reduce fast-food employment? The paper compares employment
changes at fast-food restaurants in New Jersey (treatment) with those in eastern
Pennsylvania (control) in a difference-in-differences design, and finds no
evidence of an employment decline.

**Replication target.** Tables 2–4 and Figure 1 (Table 1 is not required — its
data are restricted).

## Setup

Python 3.10+ is required (tested on 3.14). Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Reproduce everything

Place the restricted raw data at `01_DID/data/public.csv` (see "Data access"
below), then run:

```bash
python src/run_all.py
```

This rebuilds `data/processed/analysis_sample.csv` and regenerates all tables
and figures under `output/`. No manual data editing is required.

## Data access

`01_DID/data/public.csv` is restricted course data and is **not** committed to
this repository (see `.gitignore`). Obtain it from the course "Package 01"
download, extract it, and keep the folder name (`01_DID/`) and filename
(`data/public.csv`) unchanged. The processed sample and all outputs are
regenerated by `run_all.py` from this single input.
